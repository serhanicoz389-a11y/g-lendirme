Müşterilerin açacağı adres

Müşterinin telefonu bu adrese ulaşabilmelidir. Dükkândaki Wi-Fi'a bağlı telefonlar için aşağıdaki yerel adreslerden birini seçin. İnternette yayınladıysanız oradaki adresi yazın.

QR'ın hiç değişmemesi için: Modeminizin ayarlarından (genelde 192.168.1.1) "DHCP rezervasyonu" ya da "Sabit IP" bölümünde bu bilgisayara seçtiğiniz adresi kalıcı olarak atayın. Böylece bilgisayar her açıldığında aynı adresi alır ve basılı QR hep çalışır.

Telefonda sayfa açılmıyorsa
  1. Telefon, bilgisayarla aynı Wi-Fi ağına bağlı olmalı (mobil veri ile açılmaz).
  2. Önce adresi telefonun tarayıcısına elle yazıp deneyin. Açılıyorsa sorun QR'dadır: afişi yeniden yazdırın.
  3. Açılmıyorsa baslat.bat'ı kapatıp yeniden açın ve güvenlik duvarı sorusuna Evet deyin.
  4. Misafir (Guest) Wi-Fi ağları cihazların birbirini görmesini engeller; dükkânın ana ağını kullanın.
  5. Birden çok adres varsa diğerini seçip deneyin.

Dükkân bilgileri

Bu bilgiler müşteri sayfasında ve çıktılarda görünür.

🌐 İnternette Yayınlama (ücretsiz)

Müşteri sayfası https://…pages.dev adresinde yayınlanır: QR hiç değişmez, müşteri mobil veriyle de açar, barkodlar canlı kamerayla okunur, bu bilgisayar kapalıyken de çalışır.

Kurulum rehberi (bir kereliğine, ~10 dakika)

1. GitHub anahtarı oluşturun

  1. github.com/settings/personal-access-tokens/new adresini açın (GitHub hesabınızla giriş yapın).
  2. Token name: Dilek Ofis yayın yazın. Expiration: en uzun süreyi seçin.
  3. Repository access: "Only select repositories" → g-lendirme deposunu seçin.
  4. Permissions → Repository permissions → Contents: "Read and write" seçin.
  5. En alttaki Generate token düğmesine basın ve çıkan github_pat_… ile başlayan anahtarı kopyalayın (bir daha gösterilmez).
  6. Anahtarı yukarıdaki GitHub anahtarı kutusuna yapıştırıp Kaydet, ardından Şimdi Yayınla deyin. "Yayınlandı" yazısını görmelisiniz.

2. Cloudflare'de siteyi açın

  1. dash.cloudflare.com/sign-up adresinden ücretsiz hesap açın (e-posta + şifre).
  2. Sol menüden Workers & Pages → Create (Oluştur) → Pages sekmesi → Import an existing Git repository (Git'e bağlan). Ekranda yalnızca "Workers" seçenekleri görünürse sayfadaki "Pages" / "Looking to deploy Pages?" bağlantısını kullanın.
  3. Connect GitHub deyin, GitHub'da izin isteyen ekranda g-lendirme deposuna izin verin.
  4. Listeden g-lendirme deposunu seçip Begin setup deyin.
  5. Project name: dilekofis (site adresi bu olur: dilekofis.pages.dev; alınmışsa başka bir ad yazın).
    Production branch: main
    Framework preset: None · Build command: boş bırakın · Build output directory: /
  6. Save and Deploy deyin. 1–2 dakika sonra size https://….pages.dev adresi verilir.

3. Adresi kaydedin ve QR'ı basın

  1. Cloudflare'in verdiği adresi yukarıdaki İnternet sitesi adresi kutusuna yapıştırıp Kaydet deyin.
  2. Adresi telefonda açıp ürünlerin göründüğünü kontrol edin.
  3. QR Kod sekmesinde (adres önceden sabitlendiyse önce "Adresi değiştir" deyip) "İnternet adresini kullan" düğmesine basın, 📌 Bu adresi sabitle deyin ve afişi yazdırın.

Sonrasında fiyatları bu panelden değiştirmeniz yeterli: "otomatik yayınla" açıksa yaklaşık 1–2 dakika içinde internetteki sayfa da güncellenir. Fiyat değiştirmek için bu bilgisayarda baslat.bat açık olmalı; müşteriler için açık olması gerekmez.

🛒 İnternetten Sipariş Alma

Müşteri sitede sepetini onaylayınca sipariş, GitHub'daki gizli sipariş deposuna şifreli olarak bırakılır; bu program 20 saniyede bir bakıp Siparişler sekmesine getirir. Bilgisayar kapalıyken gelen siparişler depoda bekler, kaybolmaz. Dükkân Wi-Fi'ından açılan sayfadaki siparişler ise doğrudan gelir (kurulum gerekmez).

Kurulum rehberi (bir kereliğine, ~5 dakika)
  1. github.com/organizations/dilekofis/repositories/new adresini açın. Repository name: siparisler yazın, Private seçin, Create repository deyin.
  2. github.com/settings/personal-access-tokens/new adresini açın. Token name: dilekofis-siparis · Resource owner: dilekofis · Expiration: en uzun süre.
  3. Repository access: "Only select repositories" → yalnız siparisler.
  4. Permissions → Issues: "Read and write" (başka izin vermeyin).
  5. Generate token deyip anahtarı kopyalayın, yukarıdaki kutuya yapıştırıp Kaydet deyin. Durum yazısı "✔ Sipariş deposuna bağlı" olmalı. Site birkaç dakika içinde sipariş almaya başlar.

Bu anahtar müşteri sayfasına (şifrelenmiş ve gizlenmiş olarak) konur ve yalnız sipariş deposuna sipariş bırakabilir; ürünlerinize, sitenize ya da hesabınızın başka bir yerine dokunamaz. Siparişlerin içeriği dükkânın şifre anahtarıyla şifrelendiği için depoyu gören biri de okuyamaz.
